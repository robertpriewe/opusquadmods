# TYTO's Deck Highlight changelog

## 1.5 (2026-11-15)

- The outline takes the deck colour live from the deck's indicator lights.
- Dimming inactive waveforms uses less memory and works on more screens.

## 1.3 (2026-11-15)

- Outlines the selected decks' waveform rows in the deck colour.
- Outline size 1-5 px and transparency 10-100%.
- Optional: dim the big waveforms of decks that aren't selected to 30%.
