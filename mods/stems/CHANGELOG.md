# Stems changelog

## 3.1 (2026-11-25)

- Tracks with stems are marked in the browser by their own title, so they also show when the file name differs from the title (shortened names, names ending in a space, numbered copies, edited titles).

## 3.0 (2026-11-20)

- The channel 3/4 TRIM, HI, MID and LOW knobs set the stem volumes of decks 1/2 (TRIM vocals, HI instruments, MID bass, LOW drums).
- The stem buttons show each stem's volume; a centre click restores full volume.
- Tracks with prepared stems get a STEMS icon in the main browser, also when the stem folder is named "Artist - Title" or the file name was shortened.
- Fixed: a deck could play another deck's stems after a new track was loaded.

## 2.0 (2026-11-09)

- First version in the online mod catalog.
