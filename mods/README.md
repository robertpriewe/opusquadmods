# Mods

Each folder here is one mod for Robs Opus Quad Mods (R117 or later). The **OQ Mods Patcher**
reads `index.json` and installs, updates or changes mod versions on your USB stick directly,
so you don't have to download anything here by hand.

```
mods/
  index.json                         list of every mod and version (generated)
  <mod>/mod.json                     name, description, minimum firmware
  <mod>/CHANGELOG.md                 what changed in each version
  <mod>/versions/<version>/<mod>.zip the files for MODS/<mod>/ on the USB stick
```

## Installing by hand

Unzip `<mod>.zip` into `MODS/<mod>/` on the settings USB stick, then switch the mod on in
**ROBS MOD MENU** on the player.
