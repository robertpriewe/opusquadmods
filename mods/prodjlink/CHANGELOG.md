# Pro DJ Link (Experimental) changelog

## 2.0 (2026-11-20)

- Experimental. Joins the DJ Link network on the LAN port as a free player (1-4).
- Set channel 3 or 4 to PRO DJ LINK to play a linked player's track on that deck, with its waveform, cues, loops and tempo.
- Browse other players' USB sticks as LINK USBs.
- Logs are kept in MODS/prodjlink/logs: send that folder with any problem report.
