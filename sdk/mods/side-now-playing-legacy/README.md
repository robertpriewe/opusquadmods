# Side Screen Now Playing (Legacy) — USB-owned record engine

Owns live state/grid/loop presentation, waveform window, cue/metadata scheduling, privacy and overrides.
Requires the R113 coherent cached-analysis lease and side-record provider.
Shared host retains passive decode/cache, browser/transport arbitration and fixed carrier/CRC.
Uses the installed controller wire protocol; a new controller primitive can still require firmware.
